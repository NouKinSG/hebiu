# 专注与字体设置

「专注」页整合 FocusOnYourself 的计时器与统计布局，使用 Hebiu 的强调色和系统背景。需要 macOS 14 或以上（SwiftData）。

## 计时和记录

- 支持正计时、倒计时、15/25/45/60 分钟预设及 1–180 分钟自定义时长。
- 暂停、继续、重置；快捷键 ⌘↩ / ⌘R；⌘D 收起或展开统计。
- 主窗口关闭或切换页面后继续计时，菜单栏显示当前时间；主页卡片使用同一计时状态。
- 倒计时到点记为完成；提前结束满 1 分钟记为中断；正计时满 1 分钟后结束记为自由专注。不含暂停时间，不足 1 分钟的未完成会话不记录。
- 统计包含今日、本周、连续天数、近 7/30 天和最近会话。窄窗口将统计放到计时器下方。
- 正常退出会结算当前会话；异常退出后恢复进行中或暂停的计时，关闭期间到点的倒计时按真实完成时间记录。

新一轮开始触发 `focus_start`；完成触发 `focus_done`，根据设置进入休息；休息结束触发 `rest_done`。暂停后继续不会重复触发开始动作。CLI `hebiu focus [分钟]` 和 `hebiu focus stop` 使用同一套状态。

## 本地数据与恢复

专注数据库位于 `~/.hebiu/focus/FocusOnYourself.store`。计时快照、待写入记录及待处理完成事件保存在独立的 Hebiu 专注偏好域。会话 ID 在快照和历史记录间保持稳定，数据库追加和完成轮数按会话 ID 去重。写入失败保留待处理内容并重试，专注页显示错误提示。

休息截止时间随重启保留，以实际完成时刻起算。新计时或显式重置会取消旧休息，旧恢复事件不会覆盖新的计时状态。

设置 `HEBIU_HOME` 时数据库与专注偏好域均隔离。不会读取或修改独立 FocusOnYourself 的数据；本次不包含旧历史自动导入。Hebiu 原有回顾继续统计完成的倒计时轮数。

## 字体

「设置 → 字体」可选择本机字体、调整为原字号的 85–125%、预览并恢复默认，保存到 `~/.hebiu/typography.json`。主窗口、聊天、专注页和桌宠气泡即时更新。缺失字体回退为系统字体；计时数字保持系统等宽数字并跟随字号缩放，菜单栏保留 macOS 的字号约定。

## 验证

```bash
swift test                    # HebiuKit（含统计去重和写入失败回归）
bash scripts/test-focus.sh    # FocusCore + 应用整合自检
make dev                      # 本机架构 release 应用包
```

核心检查覆盖计时、暂停、记录门槛、统计、快照恢复。应用检查使用独立偏好域、临时目录和内存/临时数据库，覆盖到点前后的暂停/重置/切模式/退出、重复恢复、保存失败重试、完成事件确认、休息联动、实际数据库去重/重载以及字体边界与保存恢复。

本机验证：139 项 HebiuKit 测试、26 组 FocusCore 测试（246 checks）、应用整合自检通过；两轮真实 60 秒计时及休息（包含关窗后台运行），开始/完成/休息结束各触发两次，数据库恰好两条完成记录。另实测字体切换、字号两端、恢复默认和重启保留。系统通知横幅取决于 macOS 授权，本轮 GUI 验证主要检查动作和气泡。
